An Automated Desktop Installer

Debian Hyprland OS

A dynamically tiled Wayland desktop — Hyprland, Waybar, Rofi, and a curated set of companions — installed onto stock Debian 12 or Ubuntu 24.04 with a single script.

Overview· Features· Installation· Keybindings· Testing & CI· Source

I. Overview

From a bare shell to a tiled desktop

debian-hyprland-os turns a freshly provisioned Debian 12 (Bookworm) or Ubuntu 24.04 (Noble) machine into a complete Hyprland desktop. Because neither distribution ships a Wayland stack new enough for current Hyprland releases, the installer pulls a prebuilt Hyprland via Nix and wires it into the system alongside a curated set of companion tools — a status bar, application launcher, notification daemon, terminal, file manager, and audio stack — each themed and configured from the moment the install finishes.

Everything lives in a single script and a handful of plain-text configuration files. Nothing is hidden behind an installer GUI, and nothing is left half-configured: run it once, reboot if prompted, and land directly in a working tiling session.

✦
Terminal
$ sudo bash install.sh

II. Features

What gets installed

Hyprland
Dynamic tiling Wayland compositor with animations and blur, installed as a prebuilt package via Nix.
Waybar
A customizable status bar showing workspaces, system tray, and media controls.
Rofi
Application launcher with drun, run, and window-switching modes.
Dunst
A notification daemon with urgency-based theming.
Alacritty
A GPU-accelerated terminal emulator, dressed in the Catppuccin Mocha palette.
Thunar
A lightweight, no-nonsense file manager.
PipeWire / WirePlumber
A modern, low-latency audio and session-management stack.
Swaylock / Swayidle
Screen locking and idle management for the Wayland session.
Grim / Slurp
Full-screen and region screenshot tools.
Nvidia (optional)
Proprietary driver detection with the Hyprland environment variables it requires.

Phase Two — Planned

Wayland/X11 session switching, and a drag-and-drop application launcher, are next on the roadmap.

III. Installation

Running the installer

The script is interactive by default, asking before it touches Nvidia drivers or other optional pieces. A non-interactive mode is provided for unattended provisioning and continuous integration.

Standard install
$ sudo bash install.sh
Unattended (CI)
$ sudo bash install.sh --non-interactive --skip-nvidia
OptionEffect
--non-interactiveSkip prompts (for CI)
--skip-nvidiaSkip Nvidia GPU detection and driver install

All configuration files live in configs/ and are copied to ~/.config/ during installation, so they can be edited beforehand to customize the result.

V. Testing & CI

Verified on every push

The installer is exercised end-to-end inside a KVM virtual machine on every push, against fresh Debian 12 and Ubuntu 24.04 cloud images. Each run installs the desktop unattended, verifies that every component is present and functional, captures a screenshot of the running session, and records performance metrics.

The full pipeline — provisioning, installation, verification, and teardown — is defined in .github/workflows/test-installation.yml, with the supporting scripts under scripts/kvm/.
